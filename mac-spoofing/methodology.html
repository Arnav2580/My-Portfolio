Step-by-Step Procedure

1
View Current MAC Address

Before making any changes, record the original MAC address using ifconfig. This value is also the permanent hardware MAC stored in the NIC's firmware and will be used as a baseline to confirm successful spoofing and later restoration.

ifconfig eth0 | grep ether
2
Install Required Tools

macchanger must be installed separately. The ip and ifconfig utilities handle interface management and are part of iproute2 and net-tools respectively. On Ubuntu, install both with a single apt command.

# Update package index first sudo apt update sudo apt install net-tools macchanger -y
3
Bring the Interface Down

The Linux kernel does not allow MAC address modification on an active interface. The interface must be taken offline before the MAC register can be written. This is enforced at the kernel driver level — attempting to change the MAC while the interface is UP results in an error: SIOCSIFHWADDR: Device or resource busy.

sudo ip link set eth0 down
4
Change the MAC Address

Two methods are available: manual via ip link (direct kernel register write) or via macchanger (a higher-level tool with vendor OUI lookup, random generation, and permanent MAC restore). Both methods modify the same kernel software MAC register. macchanger additionally verifies and displays the before/after state.

Method A — set a specific MAC with ip link: sudo ip link set eth0 address AA:BB:CC:11:22:33 Method B — set a specific MAC using macchanger (preferred): sudo macchanger -m AA:BB:CC:11:22:33 eth0
5
Bring Interface Back Up and Verify

After the MAC is written to the kernel register, bring the interface back online. The new address will be visible to all network devices — the OS will use it in every outbound frame. Verify with both ifconfig and macchanger -s to confirm the software MAC and permanent MAC values.

sudo ip link set eth0 up ifconfig eth0 | grep ether sudo macchanger -s eth0
6
Restore Original MAC

macchanger stores the permanent (hardware) MAC read from the NIC's EEPROM at startup, and can restore it with the -p flag. Always restore after testing to avoid interface identification issues. The interface must be cycled down/up after restoration for the change to take effect in the kernel.

sudo macchanger -p eth0 sudo ip link set eth0 down && sudo ip link set eth0 up sudo macchanger -s eth0
